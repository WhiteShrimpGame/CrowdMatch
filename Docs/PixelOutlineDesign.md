# 整体描边（单元块）功能文档

## 0. 目标

以 Pixel 网格的**交点**为每个**单元块**的中心点，根据该交点四周（左上/右上/左下/右下）4 个 Pixel 的暴露与颜色情况，选择一张描边贴图并确定其旋转，把整个暴露区域的轮廓（含颜色分界）连成平滑描边。

---

## 1. 核心概念

### 1.1 单元块与四角映射

- 交点范围：`col ∈ [0, columns]`、`row ∈ [0, totalRows]`，共 `(columns+1)×(totalRows+1)` 个单元块。
- 单元块中心（交点）世界坐标：
  - `x = (col − columns/2) · CellSizeX`
  - `z = −(row − 0.5) · CellSizeZ`
  - 其中 `CellSizeX = unitSize + spacingX`，`CellSizeZ = unitSize + spacingZ`。
- 四角对应的 Pixel（越界视为「无 Pixel」）：

| 角 | 网格坐标 |
|---|---|
| 左上 TL | `(col−1, row−1)` |
| 右上 TR | `(col, row−1)` |
| 左下 BL | `(col−1, row)` |
| 右下 BR | `(col, row)` |

> 约定：「上」= 前 = row 小（+Z），「下」= 后 = row 大（−Z），「左」= col 小（−X），「右」= col 大（+X）。

### 1.2 角的「身份」

- `X`：暴露 Pixel（`IsExposed == true`），身份 = 其颜色 `colorId`。
- `·`：未暴露 —— 未暴露的 Pixel、无 Pixel 空格、墙/管道/未开箱障碍、越界，一律算「未暴露」。

### 1.3 三个描边要素

单元块内有四条内侧边（都汇于中心点）：

| 边 | 分隔的两角 |
|---|---|
| ↑ | TL ↔ TR |
| ↓ | BL ↔ BR |
| ← | TL ↔ BL |
| → | TR ↔ BR |

1. **边界判定**：相邻两角身份不同 → 该边描边；身份相同 → 不描边。
2. **圆角（扇形）**：出现在角 C 处，当 C 与其两个相邻角都不同，且满足——（C 是暴露格）或（C 是未暴露格、但其两个相邻格是**同色暴露**）。即描边在此 90° 拐弯（暴露区外凸角，或暴露区绕过一个未暴露格的凹角）。
3. **直线（中线）**：底侧两格（或右侧两格）为**同一暴露区**（同色暴露对）时，该条中线画成**连通直线**（构成闭合描边环）；否则该处只是圆角的开放臂。

> 「四角状态」列写为 `TL/TR/BL/BR` 的最简规范化状态；`X1≠X2` 表不同色，`·` 表未暴露。图片以「左上」为基准姿态。

| 图 | 结构 | 四角状态 | 对应情况（原文） | 旋转 |
|---|---|---|---|---|
| **A** | 圆角×1 @TL；边 ↑← | `X · · ·` / `· X X X` / `X1 X2 X2 X2` | A1 一格暴露；A2 三格同色暴露；A3 四格三同色一异色 | 把圆角对准「单独的那一角」 |
| **B** | 圆角×2 @TL,TR；**无直线（底侧开放）**；边 ↑←→ | `X1 X2 · ·` | 相邻两格暴露且不同色，另两格未暴露 | 把两个相邻异色暴露格对准 TL、TR |

| **D** | 圆角×3 @TL,TR,BL；边 ↑↓←→ | `X1 X2 X3 ·`（相邻两两异色） | 三格暴露且无相邻同色，另一格未暴露 | 把未暴露格对准 BR |
| **E** | 圆角×4；边 ↑↓←→ | 四格暴露、无相邻同色 | 四格暴露且无相邻同色 | 无（四向对称） |
| **F** | 圆角×2 @TL,TR + **横向直线**；边 ↑←→ | `X1 X2 X3 X3`（X3≠X1,X3≠X2） | 四格暴露，相邻两格同色，其余两格不同色 | 把同色对对准 BL、BR，异色对对准 TL、TR |
| **G** | 圆角×1 @TL + **横向直线**；边 ↑←→ | `X1 · X2 X2`（X1≠X2） | 三格暴露，相邻两格同色，异色格在旁侧 | 把异色格对准 TL，未暴露格对准 TR |
| **H** | 圆角×1 @TL + **竖向直线**；边 ↑↓← | `X1 X2 · X2`（X1≠X2） | 三格暴露，相邻两格同色，异色格在另一侧 | 把异色格对准 TL，未暴露格对准 BL |
| **I** | 圆角×0 + **横向直线**；边 ←→ | `X1 X1 X2 X2`（X1≠X2） | I1 四格两两相邻同色；I2 两格相邻同色暴露、另两格未暴露（X2=·） | 把两个「统一排」对准上下两排；实际为左右分界则转 90° |
| **J** | 空 | `· · · ·` 或 `X X X X` | J1 四格未暴露；J2 四格同色 | 无 |

**关键说明**：表中「四角状态」是**完全枚举**——任意 2×2 角配置都唯一落到 A–J 之一（含旋转），无遗漏、无冲突。G/H 的「顺时针/逆时针」仅用于区分这两种镜像状态（见 §3 已确认），实现时直接按上表「异色格 / 未暴露格」的位置判定即可，不纠结用词。

## 3. B 与 F 的区别（已确认）

两者都是「左上、右上两个圆角」，边集同为 {↑←→}。区别在**底侧**：

| | 底侧两格（BL, BR） | 描边结果 |
|---|---|---|
| **B** | 未暴露 | **两个圆角，底侧开放**，不构成闭合描边环 |
| **F** | 同色暴露 | 两个圆角 + **一条横向直线**连通，构成**闭合描边环**；直线与圆角衔接处平滑、**不出现尖角** |

示意（`╯` `╰` 为圆角，`─` 为直线）：

```
B（开放）        F（闭合）
   │                │
──╯ ╰──        ────┼────
```

同理：**G** 是「1 圆角 + 横向直线」（底侧同色暴露对、异色格在 TL），**H** 是「1 圆角 + 竖向直线」（右侧同色暴露对、异色格在 TL），二者是镜像关系；**I** 是纯直线（无圆角）。

---

## 4. 已确认事项（不再改动）

1. **B ≠ F**：B 两扇形开放，F 两扇形 + 一直线闭合（§3）。
2. **G/H 方向用词**：不纠结「顺时针/逆时针」，按 §2 表中「异色格 + 未暴露格」的几何位置判定。
3. **坐标方向**：上=前(row 小/+Z)、左=col 小(−X)，确认无误。
4. **问号与障碍**：未揭晓问号 → 未暴露；揭晓后 → 暴露 + `colorId`；墙/管道/未开箱 → 未暴露。

## 5. 实现要点（供后续，不含代码）

1. **渲染**：描边为覆盖层（overlay），画在 Pixel 之上；每交点一个单元块，四角取 `PixelGroup.GetItem()`（越界返回 null 视为未暴露）。
2. **判定顺序**：先算四角身份 → 按 §2 查表得到「图片 + 旋转」→ 设置 sprite 与旋转。
3. **数量**：单元块总数 `(columns+1)×(totalRows+1)`；相邻单元块的边在中点处自动衔接，形成连续描边。
4. **材质/粗细/颜色**：描边贴图的具体材质、线宽、颜色属美术资源，不在本功能逻辑内。
